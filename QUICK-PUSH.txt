TROUBLESHOOTING
====================================================================

"Authentication failed"
→ Check token, tạo token mới nếu cần

"Repository not found"
→ Repository chưa tạo hoặc URL sai

"Permission denied"
→ Repo không public, hoặc token không có repo scope

"fatal: index.lock: File exists"
→ del .git\index.lock rồi retry
